# Fall 2026 MATH 115

Course materials for MATH 115 College Algebra, organized to match the MATH 108 repo structure.

## Structure

- `notes/` — module lecture notes (Module 1 Lessons 1-6, more to follow)
- `assets/fonts/` — custom fonts. Only `a-casual-handwritten-pen.ttf` is used, by the notes files.

## Note on file paths

Overleaf compiles a document with its working directory set to that file's own folder (not the project root). All asset references in the notes use `../assets/...` accordingly.

## Note on solutions

Each notes file has a `\showsolutionstrue` toggle near the top of the preamble. Comment it out (or set `\showsolutionsfalse`) to generate a blank-space version for in-class use, matching the MATH 108 notes.
